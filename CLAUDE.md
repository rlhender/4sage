## Quick Reference

- **Project:** 4SAGE (Structured AI-Guided Experience Design) — AI-guided game design methodology
- **Website:** 4sage.dev
- **Framework:** The 4SAGE Framework (decisions cascade L0 → L6)
- **Structured blocks:** `mechanic:`, `system:`, `flow:`, `decision:`, `rule:`, `state:`, `directive:`, `answer:`
- **Priority system:** MH / SH / NH / WH
- **Template files:** `kdd/L0-vision.md` (KDDs)

## Multi-LLM Project

This project is designed to be worked on by any LLM assistant (Claude, Gemini, GPT, etc.).
All knowledge is in the files. Follow conventions in CONTRIBUTING.md.
